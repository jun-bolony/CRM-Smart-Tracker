# Security Policy

## Supported Versions

Only the latest version of the project (`v.0.9.95` and above) is supported with security updates.

| Version             | Supported          |
| ------------------- | ------------------ |
| Latest (> v.0.9.95) | :white_check_mark: |
| < v.0.9.0           | :x:                |

## Reporting a Vulnerability

We take the security of CRM-Smart-Tracker seriously. If you believe you have found a security vulnerability, please report it to us privately.

**Please DO NOT open a public GitHub Issue or Pull Request for security vulnerabilities.**

### How to report

1.  **Navigate to the "Security" tab** of this repository.
2.  Click on **"Report a vulnerability"**.
3.  Fill out the advisory form with:
    - A clear description of the vulnerability.
    - Steps to reproduce the issue.
    - Potential impact (what could an attacker do?).
    - Any suggested mitigation (if you have one).

Alternatively, you can contact the maintainer directly via their GitHub profile (jun-bolony).

### What to expect

- **Acknowledgment**: You will receive an acknowledgment of your report within 48 hours.
- **Investigation**: We will investigate the issue and determine its validity and impact.
- **Update**: If the vulnerability is accepted, we will work on a fix. We will keep you updated on the progress.
- **Disclosure**: Once the fix is ready and deployed, we will publicly disclose the vulnerability in the release notes (and credit you if you wish).

We appreciate your efforts to make this project safer for everyone. Thank you!
